# Police Command — Android builds

Police Command is a third-person police game set in an Egyptian coastal city. Patrol the streets, answer calls, chase suspects and make arrests.

## Install

1. Open the [Releases](https://github.com/mohammedemara48-code/police-command-releases/releases) page on your Android phone.
2. Download `PoliceCommand.apk` from the latest release.
3. Open it and allow installing from this source when Android asks.

Android 8.0 or newer, 64-bit (ARM64).
